# Проект Sprint_5: UI-тесты для учебного сервиса «Доска»

# О чём проект
Написаны автотесты для проверки основных сценариев на учебном сайте объявлений.
Проверяю регистрацию, вход, выход и создание объявлений.

# Что проверяют тесты
- Регистрация нового пользователя
- Регистрация с некорректным email
- Попытка зарегистрироваться с уже существующим email
- Вход в аккаунт
- Выход из аккаунта
- Создание объявления неавторизованным пользователем
- Создание объявления авторизованным пользователем

# Как запустить
1. Установить зависимости:  
   `pip install -r requirements.txt`

2. Запустить все тесты:  
   `pytest tests/ -v`

3. Запустить только один файл, например:  
   `pytest tests/test_registration.py -v`

# Структура проекта

# Какие технологии использовал
- Python 3.12
- Selenium WebDriver
- pytest
- WebDriverWait и expected_conditions (явные ожидания, без time.sleep)
- Chrome (тесты запускаются в Google Chrome)

# Примечание
Тесты независимы: каждый открывает и закрывает свой браузер. Тесты используют существующего пользователя из data.py
и генерируют email для регистрации через helpers.py..
